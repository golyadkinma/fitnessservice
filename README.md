# FitTrack — фитнес-приложение (Telegram Mini App)

FitTrack — фитнес-приложение в формате Telegram Mini App. Клиентская часть
(JavaScript, без сборщика) открывается внутри Telegram из бота, серверная часть
(Go, только стандартная библиотека) предоставляет REST API и хранит состояние
в JSON-файле.

## Функционал

- каталог продукции с поиском и фильтром по категориям;
- калькулятор индекса массы тела (шкала ВОЗ);
- шагомер с недельной статистикой (работает как заглушка: значения вносятся
  вручную, точка интеграции с сенсорами телефона оставлена в `app.js`);
- напоминания по дням недели;
- челленджи с расчётом необходимого дневного темпа;
- внутренний чат команды;
- геймификация: очки, уровни, достижения;
- бот-тренер: интеграция ИИ-сервиса (`server/ai.go`, место для ключа API
  оставлено в константе `aiAPIKey`; без ключа работает демо-режим).

## Запуск

Требуется Go 1.27+.

```
go run ./cmd/fittrack
```

Приложение открывается по адресу http://localhost:8080 (браузерный демо-режим
вне Telegram) либо как Mini App внутри Telegram.

## Тесты

```
go test ./server
```

## Маршруты REST API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | /api/health | проверка живости сервера |
| GET | /api/catalog | каталог (параметры `q`, `category`) |
| POST | /api/bmi | расчёт ИМТ |
| GET | /api/steps | недельная статистика шагов |
| POST | /api/steps | запись шагов за день |
| GET | /api/reminders | список напоминаний |
| POST | /api/reminders | создание напоминания |
| DELETE | /api/reminders/{id} | удаление напоминания |
| GET | /api/challenges | челленджи с прогрессом |
| POST | /api/challenges/{code}/join | участие в челлендже |
| GET | /api/chat | история чата |
| POST | /api/chat | отправка сообщения |
| POST | /api/ai/chat | вопрос боту-тренеру |
| GET | /api/profile | профиль и прогресс |
| POST | /api/profile | сохранение профиля |

## Настройка интеграций

1. **Ключ ИИ-сервиса** — вставить в константу `aiAPIKey` в `server/ai.go`
   (OpenAI-совместимый протокол, эндпоинт и модель настраиваются там же).
2. **Токен бота Telegram** — вставить в константу `botToken` в `server/telegram.go`
   для включения проверки подписи initData и напоминаний через бота.
